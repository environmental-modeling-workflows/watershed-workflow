Soil Properties#

Functions for manipulating soil properties.

Computes soil properties such as permeability, porosity, and van Genutchen parameters given texture properties using the Rosetta model.

Also provides functions for gap filling soil data via clustering, dataframe manipulations to merge soil type regions with shared values, etc.

watershed_workflow.properties.soil.computeVanGenuchtenModelFromRasters(ds: Dataset) → Dataset[source]#

Apply Rosetta pixel-by-pixel to gridded sand/silt/clay/bdod and add VG parameters.

Expects ds to contain variables sand (%), silt (%), clay (%), and bdod (kg/dm³, equivalent to g/cm³) with dimensions (depth, y, x). Runs Rosetta v3 on every pixel at every depth layer and appends the resulting van Genuchten parameters as new variables in the same dataset.

Parameters:

ds (xr.Dataset) – Dataset with sand, silt, clay, bdod variables, each shaped (depth, y, x).

Returns:

Input dataset with five new variables added, each shaped (depth, y, x):

  • residual saturation [-]

  • porosity [-]

  • van Genuchten alpha [Pa^-1]

  • van Genuchten n [-]

  • permeability [m^2]

Return type:

xr.Dataset

Notes

Pixels where any of the four input variables is NaN are passed to Rosetta as NaN and Rosetta propagates NaN to all output columns, which are preserved in the output arrays.

watershed_workflow.properties.soil.computeVanGenuchtenModel_Rosetta(data: DataFrame) → DataFrame[source]#

Return van Genuchten model parameters using the Rosetta v3 model.

(Zhang and Schaap, 2017 WRR)

Parameters:

data (pd.DataFrame) – One row per sample. Must include columns ‘sand pct [%]’, ‘silt pct [%]’, and ‘clay pct [%]’; may optionally include ‘bulk density [g/cm^3]’, ‘field capacity [cm^3 cm^-3]’, and ‘wilting point [cm^3 cm^-3]’ to further constrain the model (Rosetta uses progressively more accurate sub-models as more of these are provided). Missing optional columns, or NaN entries within them, are treated as unknown for that sample. The row order of the input is preserved in the output.

Returns:

van Genuchten model parameters, one row per input row, in the same order as data.

Return type:

pd.DataFrame

watershed_workflow.properties.soil.dropDuplicates(df: DataFrame, varying_columns: List[str]) → DataFrame[source]#

Removes duplicate rows by merging rows with identical values in all columns except those specified.

Rows are considered duplicates if they have identical values in all columns except those listed in varying_columns. For duplicate rows, the varying columns are aggregated into tuples containing all values from the merged rows.

For GeoDataFrames, the geometry column is automatically unioned using unary_union and cannot be included in varying_columns.

Parameters:

  • df (pd.DataFrame or gpd.GeoDataFrame) – The input DataFrame to process.

  • varying_columns (list of str) – Column names that are allowed to vary within duplicate groups. Values from these columns will be collected into tuples. Cannot include the geometry column for GeoDataFrames.

Returns:

A new DataFrame with duplicate rows merged. Returns the same type as the input (GeoDataFrame preserves CRS if applicable).

Return type:

pd.DataFrame or gpd.GeoDataFrame

Raises:

ValueError – If varying_columns includes the geometry column for a GeoDataFrame.

Land Cover Properties#

Functions for manipulating land cover and leaf area index (LAI) data.

Computes per-land-cover-class LAI time series from MODIS LAI and land cover rasters, and crosswalks land cover classifications (e.g. MODIS to NLCD) so that LAI time series computed on one classification can be applied to land cover data from another.

Also provides default property lookups and plotting utilities for LAI time series by land cover class.

Meteorology#

Functions for converting meteorological forcing data to ATS input format.

Converts raw meteorological datasets – primarily AORC, with legacy support for DayMet – into the variables and units expected by ATS (e.g. specific humidity and pressure to vapor pressure, component wind speeds to total wind speed, precipitation split into rain and snow).

Also provides utilities for allocating precipitation between rain and snow based on air temperature, and for computing a “typical year” by averaging a multi-year time series.

Functions for computing photosynthetically active radiation (PAR) at a stream surface.

Wraps a Python port of the StreamLight model, which computes solar angles, radiative transfer through riparian vegetation, and stream shading to estimate the light energy reaching the stream surface given channel geometry, riparian canopy properties, and incoming shortwave radiation.

class watershed_workflow.properties.stream_light.StreamLight[source]#

Bases: object

This class is a Python implementation of the code StreamLight (psavoy/StreamLight). Minor modifications have been made to improve numerical performance.

StreamLight is summarized in the following references:

Savoy, P., Bernhardt, E., Kirk, L., Cohen, M. J., & Heffernan, J. B. (2021).

A seasonally dynamic model of light at the stream surface. Freshwater Science, 40(April), 000–000. https://doi.org/10.1086/714270

Savoy, P., & Harvey, J. W. (2021). Predicting light regime controls on primary

productivity across CONUS river networks. Geophysical Research Letters, 48, e2020GL092149. https://doi.org/10.1029/2020GL092149
