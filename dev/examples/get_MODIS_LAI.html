Working with MODIS for Land Cover and LAI data#

MODIS provides satellite image data including land use/land cover (LULC) and Leaf Area Index (LAI). Two managers are available:

  • ManagerMODISEarthdata — downloads directly from NASA LP DAAC via earthaccess. Synchronous, no account beyond a free NASA Earthdata login, recommended for new workflows.

  • ManagerMODISAppEEARS — submits an asynchronous job to the NASA AppEEARS portal. Requires an AppEEARS account configured in watershed_workflowrc.

Both return similar xr.Dataset objects, but not identical.

This will also demonstrate how to work with non-blocking downloads/job requests.

Download MODIS data via NASA Earthdata (earthaccess)#

ManagerMODISEarthdata provides the same LAI and LULC products as the AppEEARS manager but downloads directly from NASA LP DAAC without an asynchronous queue.

Requirements:

  • earthaccess and pyhdf packages (conda-forge): conda install -c conda-forge earthaccess pyhdf

  • A free NASA Earthdata account with credentials in ~/.netrc:

machine urs.earthdata.nasa.gov login <username> password <password>

The call signature is identical to ManagerMODISAppEEARS, but the download is synchronous — no waiting or polling needed. But it does take a while to download, so let’s do the download non-blocking and continue.

source_ed = watershed_workflow.sources.ManagerMODISEarthdata()
ed_task = source_ed.requestDataset(watershed.exterior, watershed.crs, startdate, enddate, out_crs=crs)

Compute time series of LAI#

First, MODIS is “real” data, and so has leap year. Now that we use AORC, which includes leap day, we can keep it

# MODIS data comes with time-dependent LAI AND time-dependent LULC -- just take the mode to find the most common LULC
modis_data_app['LULC'] = watershed_workflow.utils.computeMode(modis_data_app['LULC'], 'time_LULC')

# now it is safe to have only one time
modis_data_app = modis_data_app.rename({'time_LAI':'time'})

Form the dynamic time-series.#

The raw data is integrated in space by intersecting each LULC index with the LAI raster and summing over that mask. This is done for each time of LAI observation to form a time series.

From here we will work with just one of the datasets.

modis_data = modis_data_app

# compute the dynamic time series
lai_df = watershed_workflow.properties.land_cover.computeTimeSeries(modis_data['LAI'], modis_data['LULC'], 
                                                                      polygon=watershed.exterior, polygon_crs=watershed.crs)
lai_df

# plot the dynamic data
fig = plt.figure()
ax = fig.add_subplot(111)

ts = cftime.date2num(lai_df['time'], f'days since {start_year}-01-01')  
for column in lai_df:
    if column != 'time':
        ax.plot(ts, lai_df[column], label=column)
ax.set_ylabel('Leaf Area Index [-]')
ax.set_xlabel('time')
ax.legend()
plt.show()

Form data for a typical year#

In addition to the dynamic data, we need a typical year for cyclic steadystate spinup purposes. To do this, we need NO leap day

# remove leap day (366th day of any leap year) to match our Noleap Calendar
lai_df_noleap = watershed_workflow.utils.filterLeapDay(lai_df)

# also compute a typical year of LAI
typical_df = watershed_workflow.utils.computeAverageYear(lai_df_noleap, '2000-01-01', output_nyears=10)

# plot the dynamic data
fig = plt.figure()
